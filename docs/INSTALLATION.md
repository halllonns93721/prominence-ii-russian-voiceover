# Installation

Requirements: Minecraft 1.20.1 (Fabric), Prominence II: Hasturian Era v4.1.2,
`Prominence_II_Russian_Voice_Pack_Final.zip` (v1.0.0).

1. Close the game.
2. Copy `Prominence_II_Russian_Voice_Pack_Final.zip` into `minecraft/resourcepacks/`
   (do not unpack it).
3. Launch the game → Options → Resource Packs.
4. Move the Russian voice pack to the **top** of the active list (above other packs
   that touch the same sounds), then confirm.
5. If Russian subtitles are used, enable the matching subtitle companion and select
   Russian (`ru_ru`) so spoken lines and displayed text agree.

## Rollback

Disable or remove the pack. The mod JAR immediately restores the original English voices.
No game files are modified by installation.

## Troubleshooting

- **No Russian voices heard:** the pack must be enabled (not just present in the folder);
  check it sits above any other voice/sound pack.
- **Another pack overrides sounds:** keep only one voice pack enabled.
- **Pack shows as incompatible:** it targets `pack_format` 15 (Minecraft 1.20.1). Do not use
  it on far-newer game versions without revalidation.
